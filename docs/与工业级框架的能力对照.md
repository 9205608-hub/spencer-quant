# Spencer 框架 vs 工业级多因子平台 —— 能力对照

对照对象是"工业级多因子研究平台的通行形态"（概念级描述，不含任何机构的
私有实现细节）。目的：知道自己在哪一层、差距具体差在哪、哪些差距是两天
能补的、哪些是数据与团队规模决定的。

**对比铁律：只做结论级对比，不做数字级对比。** 两套系统的宇宙、中性化、
成本口径全不相同，任何"我的 IC 0.03 vs 它的 IC 0.04"式并排都是错的。
能比的是判断：同一个因子概念在两边是否都指向"有独立信息/方向一致/
逐年稳定"。

## 能力对照表

| 维度 | Spencer v0.2 (Mac 单机) | 工业级通行形态 | 差距性质 |
|---|---|---|---|
| 数据仓库 | baostock 日线按需拉取, 长表+宽表 parquet | 多源数据每晚增量调度入仓, 统一清册与字段登记 | **数据源与运维**, 架构思想已同构 |
| 宇宙 | 成分股快照 (幸存者偏差, 明示) | 历史时点成分+上市/退市/ST 全状态 | **数据源**, 补 PIT 成分表即可收窄 |
| 复权 | 后复权收益轴 + 不复权价格轴双轨 | 同思想, 多一层供应商交叉校验 | 已同构 |
| 行业/风格 | 行业快照 + 自算五风格 (缺 VALUE) | 完整风格模型, 行业时点化, 因子协方差矩阵 | **半数据半工程**, M6 继续补 |
| 中性化 | 逐日截面回归残差, 因子/标签两侧, 三档读数 | 同一数学, 档位更多、口径成体系 | **已同构**, 这是本次最大收获 |
| 评估面板 | 六件套 (IC/保守t/逐年/热力图/秩自相关/分层) | 更多年份×多口径×多 horizon 的标准面板 + 验证契约 | 思想同构, 覆盖面差数据年限 |
| 回测 | 研究级近似成本分层多空 | 撮合级模拟 + 组合优化器 + 容量/冲击建模 | **工程深度**, M5 只到第一层 |
| 研究纪律 | append-only 台账 + N 计数; 预注册在 alpha-court | 团队级流程制度 | 个人版反而可以更严格 |
| 算力 | Mac 单机 CPU | GPU 集群 + 任务调度 | 资源, 非能力 |

## 判断级对照的一个实例（chip_age）

同一个"筹码沉淀"概念，公开教科书版一行递推（换手率衰减的平均持仓龄），
在 Spencer 框架公开数据、快照宇宙、自算中性化的口径下，与实习期间在
工业级口径下得到的判断做方向性对照：**是否有独立于风格的信息、方向
是否一致、逐年是否大体稳定**。两边数字永不并排——判断一致即为"框架
能出正确判断"的证据，判断不一致则优先怀疑自己这边的口径缺陷（宇宙
快照/风格不全/成本近似），这个怀疑顺序本身也是方法论的一部分。

## 差距总结（诚实版）

两天建出来的是**研究管线的完整拓扑**：每一环都在、每一环都是公开
方法论的正确实现、每一环都有测试。差的是三样东西——
1. **数据的深度**（PIT 成分/行业、财报、更长历史、分钟与逐笔）；
2. **回测的深度**（撮合、优化器、容量）；
3. **年头**（工业级平台是团队×年的沉淀, 单机两天只能给出骨架）。

骨架对了，肉可以慢慢长。反过来（肉厚骨歪）才是不可救的。
