# Spencer 框架使用指南

README 是门面，这里是说明书：每个入口做什么、产出什么、参数怎么调、
读数怎么判。所有命令都在仓库根目录执行，均已实跑核对。

## 0. 这套系统解决什么问题

日频截面因子研究的完整闭环：从公开数据拉取，到"这个因子扣掉风格搭便车、
扣掉成本、扣掉多重检验之后还剩多少"的最终判决。它刻意不做的事（撮合级
回测、容量模型、实盘下单）在 README 设计边界一节写明。

一个因子在本系统里走完的路：

```
行情/财报拉取(PIT) → 宽表存储 → 因子计算(带缓存指纹)
  → 三档中性化读数(@raw / @size_neut / @full_neut)
  → 评估面板六件套(RankIC/NW-t/逐年表/月度热力图/分层/多空)
  → 成本后分层回测(一字板可成交过滤)
  → 组合构建(缓冲 top-N 或 FISTA 优化器)
  → 研究纪律(append-only 台账 → DSR/PBO 多重检验缩水)
```

## 1. 安装

```bash
pip install -r requirements.txt   # baostock/akshare/pandas/numpy/pyarrow/matplotlib/PyYAML/scipy
python tests/test_core.py         # 不碰网络, 全部断言应通过
```

Python ≥ 3.10。测试全部用合成数据，装完先跑一遍确认环境无恙。

## 2. 五分钟冒烟

```bash
python examples/quickstart.py --limit 80
```

做了什么：拉 80 只股票的日线（首跑需要网络，之后走本地 parquet 缓存）→
建宽表 → 算全部 7 个注册因子 → 每个因子跑三档中性化读数 → 成本后分层
回测 → 结果追加进实验台账。

产出在哪：`output/` 下每因子×每档一张面板图 `panel_<因子>@<档>.png` 和
逐年表 `yearly_<因子>@<档>.csv`；台账追加到 `research_ledger.csv`；终端
打印每档的 IC 均值 / ICIR / 两套 t 值 / 逐年一致性。

去掉 `--limit` 即全量 a800（沪深300∪中证500 快照宇宙）。注意：快照宇宙
有幸存者偏差（30问#6），只适合上手与冒烟，严肃结论一律用下一节的 PIT 口径。

## 3. 正式研究工作流（PIT 口径，无幸存者偏差）

```bash
python examples/fetch_pit.py        # ① 全市场 PIT 数据(含退市股, ~40min, 断点续跑)
python examples/pit_final_run.py    # ② 正式口径终跑: PIT宇宙 + 三档面板
python examples/opt_backtest_run.py # ③ 优化器逐期回测(依赖①②的产出)
```

① 抓的是全市场含退市股名单的日线——退市股在它活着的时候必须在样本里，
这是消除幸存者偏差的前提。中断重跑会从断点续传。
② 用 `config.yaml` 的 `universe_pit` 参数现构造逐日 PIT 宇宙（新股预热
`min_list_days`、剔 ST、流动性截面前 N），在此宇宙上重跑三档面板，文件名
带 `_pit` 后缀。
③ 在 PIT 数据上跑 FISTA 优化器的逐期组合回测（τ 成本前置），输出超额
净值曲线与换手/成本对账。

## 4. 常用配方

### 4.1 加一个自己的因子

```python
# 写在 spencer/factor/zoo.py 或任何被 import 的模块里
from spencer.factor.base import factor
from spencer.data.store import WideStore

@factor("my_factor")                       # 注册名全局唯一
def my_factor(store: WideStore) -> pd.DataFrame:
    adj = store.load("adj_close")          # 可用字段见 data/ 宽表
    return adj.shift(1) / adj.shift(21) - 1.0   # 返回 date×code 宽表
```

之后 `quickstart.py` 会自动把它纳入全流程。注意事项：
- 只允许用 T 日及以前的数据（前视闸的责任在因子作者这一侧）；
- 因子缓存按"函数源码指纹 + 数据形状指纹"双判据自动失效——改了函数体
  或换了数据，缓存自动重算，不需要手动清；
- 想带登记元信息：`@factor("my_factor", author="you", tags=["price"])`，
  入库门禁（`factor/verify.py` 七关）会用到。

### 4.2 三档读数怎么读

同一因子三档 IC 的落差本身就是信息：

- `@raw` 高、`@full_neut` 塌掉 → 收益基本是风格搭便车（常见于与市值/
  动量高度同源的因子），中性化后没有独立信息；
- 三档都稳、逐年全正 → 才值得进下一步成本后回测；
- 判读顺序：先看**逐年一致性表**（单年驱动=假信号），再看 IC 均值。

### 4.3 面板六件套逐格说明

| 格 | 内容 | 怎么读 |
|---|---|---|
| cumulative RankIC | 逐日 RankIC 累计曲线 | 斜率稳定>0 好；台阶式跳变=单事件驱动，警惕 |
| monthly IC heatmap | 年×月 IC 均值 | 绿色是否连续；某一年整行深色=该年主导 |
| yearly table (csv) | 逐年 IC/ICIR/N | **首要判据**：positive 列是否全 True |
| quantile bars | 分层年化收益(毛) | 单调性；顶层塌陷（如 Q4>Q5）如实呈现 |
| long-short cumulative | 多空累计(毛) | 形状与回撤段；数字判断以成本后为准 |
| 汇总统计 | IC 均值/ICIR/两套 t | 见下 |

两套 t 值：`t_stat_conservative` 是有效样本按 n/horizon 缩水的下界式
安全垫；`t_stat_nw` 是 Newey-West（Bartlett 核，lag=horizon）标准答案。
两者分歧大本身是诊断信号（自相关结构偏离纯重叠假设）。

### 4.4 成本后回测的口径开关

```python
from spencer.backtest.layered import layered_backtest, tradability_masks

can_buy, can_sell = tradability_masks(store)      # 一字板可成交掩码
res = layered_backtest(factor_df, fwd1, q=5, rebal_days=5,
                       cost_bps=15.0,             # 单边费率地板(佣金+印花+点差)
                       can_buy=can_buy, can_sell=can_sell,
                       impact_bps_extra=0.0)      # 额外线性冲击预算
```

必须知道的三条口径（详见 `layered.py` 模块 docstring，每条假设都写明）：
掩码按**执行日**取值而非信号日；掩码/无掩码两条路径的成本与换手计账口径
不同，**数字不可跨路径并排**；成本敏感性看 `long_net` 不看 `ls_net`
（空头腿成本在多空差里符号为正的已知怪癖）。

### 4.5 多重检验缩水（研究纪律的最后一关）

```python
from spencer.discipline.stats import dsr_from_ledger

out = dsr_from_ledger(observed_sharpe=0.05, T=2000)   # 每期 Sharpe, 不年化!
# out["dsr"] > 0.95 才算过 95% 置信; out["n_trials_from_ledger"] 必须一起报
```

N（试过多少次）从 append-only 台账 `research_ledger.csv` 直读，不许手填
——手填的 N 永远偏小。**报 DSR 必须连着 N 一起报**。本框架当前最好的合成
读数是 DSR 0.47（N=60 下不显著），README 原样写着——这个系统的设计目标
就是让它自己说出这句话。

### 4.6 预注册（防"先看结果再定判据"）

`spencer/discipline/preregister.py` + `tickets/`：先把假设、判据、试验
预算、止损条款写成工单并冻结，再跑计算。`tickets/20260724_icir_crash_protection.json`
是一份实例（判据先于计算冻结，一次性判定不追加调参）。

## 5. config.yaml 速查

| 段 | 键 | 含义 |
|---|---|---|
| 顶层 | `universe` | 快照宇宙：hs300 / zz500 / a800 |
| 顶层 | `start` / `end` | 样本窗；end 空=取到最新 |
| `label` | `horizon` | 前瞻收益天数（T+1 → T+1+h） |
| `universe_pit` | `min_list_days` 等 | PIT 宇宙构造参数（新股预热/剔ST/流动性截面） |
| `portfolio` | `top_n` 等 | 组合默认参数（rebal_sweep 扫参高原上按成本稳健取） |

所有模块只从这里读参数，不各自硬编码——改口径只改一处。

## 6. 判读纪律速查（血泪出处见 README 硬规矩节）

1. 逐年一致性 > 裸均值；单年驱动=假信号。
2. 对比必同口径：同宇宙/窗口/中性化/末端，跨框架数字永不并排。
3. 毛收益只用于排序讨论，结论必须成本后。
4. 报显著性必须带 N（台账直读）与两套 t。
5. 快照宇宙只做冒烟；正式结论一律 PIT 口径。
