# 量化研究系统必答 30 问（活清单，30 只是起点）

这份清单是本项目的主线：一个日频因子研究系统在工程上必须回答的问题。
每一问附「不回答会怎么死」和「本项目的回答(或欠账)」。学完 = 有能力从零
搭一套自己的研究系统。全部内容来自公开方法论与通用工程经验。

**为什么是 30？** 老实说：凑整的包装，没有任何神圣性。真实的清单是活的——
每往下建一层就会踩出新问题（见文末追加区，M5/M6 建设当天就加了 4 问）。
如果哪天这个清单不再增长，说明系统停止进化了，那才是坏消息。

## 一、数据层 (8 问)

**1. 复权用前复权还是后复权？**
死法: 前复权用今天的除权信息改写历史价格 → 历史截面被未来污染。
回答: 收益轴一律后复权; 价格位置/筹码类因子用不复权真实价。(`fetch.py`)

**2. 换手率的分母是什么口径？**
死法: 总股本/流通股本/自由流通三种口径差数倍, 混用后递推类因子全错。
回答: baostock turn=量/流通股本, 统一转小数 clip[0,1], 停牌置0, 并在文档
写死口径。(`fetch.py`)

**3. 停牌日和涨跌停怎么进数据？**
死法: 停牌日价格 ffill 后当有效样本 → IC 被虚假的"零收益"稀释; 涨跌停
当日实际不可成交 → 回测收益虚高。
回答: 落盘 is_trading 截面过滤停牌; 涨跌停已补齐——tradability_masks()
判"一字板"(保守下界, 盘中打开的仍算可成交), layered_backtest 可选注入
can_buy/can_sell, 掩码按**执行日**取值(T+1 建仓日的一字板才是真拦路虎)。

**4. 数据末端在哪, 谁负责知道？**
死法: 数据更新了、因子没更新, 或反之 —— 静默用旧数据出新结论。
回答: store.end_date() 是唯一末端锚点; 因子缓存新鲜度判据 = 因子末端
== 数据末端, 不齐即重算。(`store.py`, `base.py`)

**5. 长表还是宽表？**
死法: 研究端每次都从长表 groupby/pivot → 慢 + 每个人写一遍对齐逻辑。
回答: 落盘长表(保真), 研究用宽表(date×code, 每字段一文件) —— qlib 式
数据层思想。(`store.py`)

**6. 指数成分股是快照还是时点(PIT)？**
死法: 用今天的成分股跑五年回测 = 幸存者偏差 + 指数纳入效应白送alpha。
回答: v0.1 只有快照(baostock 限制), README/路线图 M7 明示欠账 —— 知道
自己错在哪比假装没错重要。

**7. 新股/次新股什么时候允许进截面？**
死法: 上市首月的换手/波动是另一个物种, 递推类因子初值也没意义。
回答: 60 交易日预热期(warmup), 递推因子内部再独立硬约束。(`zoo.py`)

**8. 原始数据要不要清洗？**
死法: 在落盘层"顺手修数据" → 下游永远不知道数据被谁动过。
回答: 落盘层只做类型转换与口径统一, 过滤在使用端做, 原始值不删改。

## 二、因子层 (6 问)

**9. 因子的输入输出契约是什么？**
死法: 有的因子吃长表有的吃宽表, 有的返回 Series 有的返回矩阵 → 每接一个
因子都要重新对齐一次。
回答: 契约唯一: fn(store) -> date×code 宽表。注册表统一管理。(`base.py`)

**10. 因子值算到哪一天？**
死法: 因子末端落后数据末端 N 天, 交付后线上第一天就没值。
回答: compute() 内 assert 因子末端==数据末端, 违反即拒绝出厂。(`base.py`)

**11. 去极值/标准化在时间轴还是截面轴？**
死法: 跨时间做标准化 → 用未来分布刻画今天 = 前视。
回答: 预处理只在截面(单日)内做; 跨时间的操作属于因子构造, 边界写进
模块文档。(`ops.py`)

**12. 中性化剥什么、怎么决定？**
死法一: 不剥 → 因子其实是市值/行业的换皮。死法二: 照抄一套固定中性化
集合 → 剥不到该剥的(每个因子的暴露结构不同)。
回答: 先量因子对风格的暴露(回归R²/|β|), 再决定剥什么。v0.1 提供市值
中性化, 行业与完整风格集在 M6。(`ops.py`)

**13. 因子方向怎么统一？**
死法: 一半因子值大看多一半值大看空, 组合和面板全乱。
回答: 交付惯例「值大=看多」; orient() 翻正并强制披露翻转动作(它是一次
样本内决策)。(`ops.py`)

**14. 因子缓存怎么失效？**
死法: 改了因子代码, 缓存还是旧逻辑的值; 或宇宙换血/数据重拉后旧矩阵
冒充新矩阵。
回答: 已补齐——缓存键 = 因子函数源码 sha256 + 数据形状指纹(起止日期/
行数/列名哈希), sidecar json 存指纹, 不匹配即重算; 末端对齐仍作兜底。
已知近似(明示): 指纹不盖被调用的辅助函数源码、不盖中间数据的原地修订。

## 三、评估层 (8 问)

**15. 前瞻收益怎么对齐才没有前视？**
死法: 今天的因子对今天的收益 → IC 虚高一个数量级, 全盘作废。
回答: fwd = adj.shift(-(1+h))/adj.shift(-1) - 1 —— T日因子最早吃 T+1 起
的收益。测试里手工核对一格。(`panel.py`, `test_core.py`)

**16. IC 用 Pearson 还是 Spearman？**
死法: Pearson 被单票极端值劫持。
回答: 主判据 RankIC(Spearman); 均值/标准差/ICIR/t 一起报, 不报单数字。

**17. 重叠窗口的 t 值怎么缩水？**
死法: 5日收益逐日采样 → 相邻IC强自相关 → t 值虚高 √5 倍。
回答: 保守口径 n_eff = n/horizon 再算 t。更精细的 Newey-West 是升级项。
(`panel.py`)

**18. 看均值还是看逐年？**
死法: 三年里一年暴赚两年阴跌, 均值仍然漂亮 → 单年驱动的假信号入库。
回答: 面板强制输出逐年表和"逐年全正"布尔位; 判读以逐年一致性优先。

**19. 换手怎么在入库前预警？**
死法: IC 很美的快因子, 成本后净收益为负。
回答: 秩自相关(lag=5)做换手代理, 面板必报; 完整的成本后分层回测在 M5。

**20. 分层收益为什么必看？**
死法: IC 可以由中段单调贡献, 多头端其实平坦 → 实盘做多没肉。
回答: 分5层年化柱状图进面板, 看单调性与两端形态。

**21. 两个因子怎么比才公平？**
死法: 不同年份集/宇宙/中性化/末端的数字并排下结论。
回答: 对比必同口径(同宇宙/窗口/中性化/末端), 面板参数全部从单一配置读。

**22. 结果怎么才算可复现？**
死法: "上次跑是0.03来着" —— 同 spec 复跑不出同数字, 数字不算数。
回答: 配置单一真相源 + 因子缓存 + 台账记 params; 随机性环节(未来的模型
因子)必须锁种子。

## 四、统计纪律 (4 问)

**23. 试了 100 个因子挑出 1 个, t=3 还可信吗？**
死法: 多重检验下 t=3 在 N=100 时几乎必然出现 → 赢家诅咒。
回答: 台账 append-only 记全每次试验, N 是 DSR(缩水夏普)/BHY 校正的输入。
(`ledger.py`, 完整实现桥接 alpha-court)

**24. 何时写下判据？**
死法: 先看结果再定"及格线" → 判据永远刚好让结果及格。
回答: 预注册 —— 动手前写死判据/试验预算/止损线(alpha-court 工单制)。

**25. 参数敏感性怎么查？**
死法: 因子只在 (20,5) 这组参数活着, 邻域全死 → 过拟合的孤峰。
回答: 邻域参数矩阵全跑全报(台账每格一行), 看的是"高原"不是"山尖"。

**26. 负结果怎么处理？**
死法: 只留成功记录 → 下一个人(或三个月后的自己)把死路重走一遍。
回答: 负结果照进台账+写判词; "判死也要给出统计功效"(样本够不够大到
足以判死)。

## 五、工程横切 (4 问)

**27. 参数散落在哪里？**
死法: 同一个宇宙定义在五个脚本里五个写法, 改一处漏四处。
回答: config.yaml 单一真相源, 模块禁止私藏常数。(`config.py`)

**28. 什么样的检查该变成 assert？**
死法: "口径靠自觉" → 每个坑每个新人各踩一遍。
回答: 凡是踩过的坑, 升级为代码里的硬断言(末端对齐/索引单调/唯一), 
让错误在出厂前爆炸, 而不是在结论里潜伏。(`store.py`, `base.py`)

**29. 流程跑通之后放哪里？**
死法: 留在聊天记录/临时目录 → 下次从零再来。
回答: 当场沉淀成可执行的 example + 文档(本项目 quickstart 即 runbook)。

**30. 系统的边界在哪里？**
死法: 什么都自己造 → 造回测轮子三个月, 因子一个没研究。
回答: 先穷尽成熟公开件(qlib/alphalens/vectorbt 的思想或实现), 只造两类
东西: ①理解性重写(为了学) ②市面确实没有的(纪律层)。造之前先说清属于

## 追加区（建设中踩出来的, 持续增长）

**31. 行业分类是快照还是时点？(2026-07-22, 建M6时)**
死法: 公司换行业(如地产转物业)后, 今天的分类改写历史截面 → 行业中性化
在历史上剥错行业。
回答: v0.2 用快照(baostock 限制), 与宇宙快照同源欠账, 文档明示。

**32. 风格中性化的标签侧要不要也中性化？(2026-07-22)**
死法: 只中性化因子、不中性化收益 → IC 里仍混着行业与风格 β 的收益,
读数不是纯 alpha。
回答: 三档读数里 full_neut 档因子与标签**两侧都残差化**(Barra 纯因子
收益思想); 三档 IC 落差本身就是信息——量出因子有多少收益是风格搭便车。

**33. 风格因子自己算, 缺哪个最伤？(2026-07-22)**
死法: 缺 VALUE(BTOP) → 价值暴露剥不掉, 低估值堆积的因子被误读为 alpha。
回答: 已补齐——BTOP = PIT 每股净资产/价格(spencer/risk/fundamental.py):
akshare 按报告期 bulk 拉业绩报表, **披露日次日生效**(保守口径)再 ffill 到
日频。已知近似明示: 披露日取最新公告日期非首披日、送转后股本口径错位。

**37. 换手惩罚 τ 该设多大？(2026-07-24, τ前沿实验)**
死法: τ=0 → 优化器每期重新最优化, 换手 5.8x, alpha 被成本吃干净
(实测净超额 −0.07%); τ 拍脑袋设大 → 组合僵死跟不上信号。
回答: **τ ≈ 真实单边成本**。实测前沿(只动 τ, 其余全冻结):
τ=0/5/15/50bp → 净超额 −0.07%/+0.40%/+2.22%/+2.15%, 峰值恰在
τ=15bp = 实际成本率, 15→50bp 是平台不是悬崖。经济学解释: 目标函数里
给自己记的过路费应当等于真实过路费, 记少了乱换手, 记多了错过该换的。
副产物(反直觉但可解释): 主动份额随 τ **上升**(0.43→0.59) —— L1 惩罚
锚在 w_prev 而非 w0, τ 大则"离开基准后不回头"(回头也要付费), 主动
暴露因此累积; τ=0 时每期重解, 被 λ 拉回基准附近。

**38. 参数扫描扫哪个旋钮？(2026-07-24, λ前沿失效)**
死法: 挑一个"看起来重要"的参数扫一遍, 三个取值给出几乎相同的解,
白跑一轮还以为"参数不敏感=稳健"。
回答: 先判断**杠杆序**。本框架实测: τ ≫ cap/暴露带 ≫ λ —— τ 的 L1
门槛相对 α 量纲(IC×特异波动≈万分之五)是压倒性的, λ 的二次项在该区域
只是二阶修正。扫参前先估各项在目标函数里的量级, 别扫死旋钮。

**35. 重叠窗口下 t 值怎么修正？(2026-07-23, 建M3时)**
死法: horizon=5 的前瞻收益逐日采样 → 相邻 IC 强自相关 → 朴素 t 虚高
约 √5 倍, 假显著遍地。
回答: 双读数并排——保守缩水(n_eff=n/h, 下界式安全垫) + Newey-West
(Bartlett 核, lag=h, 标准答案); 两者分歧大本身就是诊断信号。

**36. 评估标签的空间 = 兑现收益的空间吗？(2026-07-23, model_gb 证伪案)**
死法: 对风格中性残差标签的拟合优度当成 alpha——本仓活案例 model_gb:
残差标签 IC 0.048/9 年全正, 但兑现率只有 56%, 且按预测分层吃**原始**
次日收益时预测最高层全场最差(多空为负)。模型对残差拟合越好, 离可交易
组合可能越远。
回答: 验收口径必须落在可交易空间(raw 收益的分层/净值), 残差 IC 只当
过程指标; 若信号本质是中性化信号, 就按"带行业+风格对冲腿"的多空组合
去设计和计费, 两条路必选其一。全过程见 output/falsify_model_gb.md。

**34. 回测的成本模型粗到什么程度就不诚实了？(2026-07-22, 建M5时)**
死法: 无成本回测宣布"净收益"; 或用一个精确到骗自己的成本模型。
回答: 研究级近似=单边固定 bps × 名义换手, 每条假设写进 docstring;
它回答排序问题(扣成本后还剩不剩肉), 不回答容量问题。宣布数字时带口径。
